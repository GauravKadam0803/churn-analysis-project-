🎯 Project Objective

The objective of this project is to analyze customer data to understand the factors that influence customer churn and identify customers who are at a higher risk of leaving the company. Using Python and data analysis techniques, the project focuses on cleaning and exploring the dataset, performing exploratory data analysis (EDA), identifying patterns and trends, and generating actionable business insights.

This project aims to:

- Analyze customer demographics, services, and account information.
- Identify the key factors contributing to customer churn.
- Perform data cleaning, preprocessing, and exploratory data analysis (EDA).
- Visualize customer behavior and churn trends using charts and graphs.
- Discover relationships between customer attributes and churn.
- Provide data-driven recommendations to improve customer retention and reduce churn.
- Demonstrate practical data analytics skills using Python, Pandas, NumPy, Matplotlib, and Seaborn.
